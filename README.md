# 🤖 IA Assist Admin - Sistema de Gestión Inteligente

## 📌 Descripción del Proyecto
**IA Assist Admin** es una plataforma de software diseñada para optimizar y automatizar la gestión administrativa, clasificación de solicitudes, priorización y generación de reportes en entornos de administración (como Propiedad Horizontal) mediante un agente externo de inteligencia artificial.

## 📁 Estructura del Expediente Documental
* `00_Leeme_y_Control/` -> Índice maestro de versiones y control del expediente.
* `01_Gestion_Proyecto/` -> Actas de inicio, cronograma y riesgos.
* `02_Narrativa_Cliente/` -> Narrativa, contexto, problema, actores y objetivos
* `03_Levantamiento_Informacion/` -> Instrumentos, resultados y análisis de entrevistas/encuestas
* `04_Requisitos_IEEE29148/` -> Especificación formal de requisitos funcionales y no funcionales.
* `05_Scrum/` -> Sprints, Product Backlog, Daily Scrum y Retrospectivas.
* `06_Historias_Usuario/` -> Historias priorizadas con criterios de aceptación.
* `07_Product_Backlog/` -> Backlog maestro y registro de cambios.
* `08_BPMN/` -> Modelos de proceso AS-IS y TO-BE.
* `09_UML/` -> Casos de uso, actividades, estados, clases y especificaciones.
* `10_Arquitectura_IEEE1016/` -> Documento de Descripción de Diseño de Software (SDD).
* `11_Base_Datos/` -> Modelo ER, modelo lógico y diccionario de datos (3FN).
* `12_UX_UI/` -> Sistema de diseño visual, wireframes y mockups.
* `13_Prototipo/` -> Ficha del prototipo navegable y evidencias de pruebas.
* `14_Presentaciones/` -> Socializaciones parciales y sustentación final.
* `15_Evidencias_Trello/` -> Enlace al tablero y capturas fechadas de seguimiento.
